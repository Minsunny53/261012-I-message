Firebase 설정 도움말

① 코드 상단 FIREBASE_CONFIG에 Firebase 웹앱 설정을 붙여 넣고, ② Authentication에서 Google 로그인을 켜고, ③ Firestore 규칙을 아래처럼 설정하세요. (읽기는 모두, 쓰기는 관리자 메일만)

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /appConfig/{doc} {
      allow read: if true;
      allow write: if request.auth != null
                   && request.auth.token.email == "관리자메일@gmail.com";
    }
  }
}

개인정보·데이터 안내

  • 이름은 쓰지 않아요. 친구 이름도, 내 이름도, 전화번호·주소·이메일도 쓰지 않아요. 그런 내용이 보이면 앱이 막아요.
  • 저장되는 것: [선생님께 제출]을 누른 때만, 학급 코드와 번호, 내가 쓴 연습 내용이 선생님 학급 기록에 저장돼요. 이름과 구글 계정은 저장하지 않아요.
  • 저장되지 않는 것: AI 선생님과 나눈 대화는 기록으로 남기지 않아요.
  • AI 선생님: 질문할 때 쓴 글은 AI(Google Gemini) 서비스로 보내져 답을 만들어요. 개인정보처럼 보이는 글은 보내지 않아요.
  • 누가 볼 수 있나요: 우리 반 선생님(비밀번호로 잠긴 기록)과 서버 관리자만 볼 수 있어요. 기록은 선생님이 언제든 지울 수 있고, 오래된 기록은 자동으로 지워져요.
